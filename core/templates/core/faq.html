Preguntas frecuentes

Resuelve tus dudas sobre el catálogo y el carrito.

Antes de empezar

¿Qué productos puedo encontrar?

Componentes para computadores, parlantes, audífonos y accesorios de carga. Puedes revisar los ocho productos en Inicio.

¿Cómo añado productos al carrito?

En Inicio, presiona «Añadir al carrito» debajo de un producto. Luego abre «Carrito» en el menú para ver el resumen.

¿Puedo cambiar las cantidades o quitar un producto?

Sí. Usa los botones + y − del carrito para ajustar las cantidades, o «Quitar» para eliminar un producto. También puedes vaciar el carrito completo.

¿En qué moneda están los precios?

Todos los valores se muestran en pesos chilenos (CLP). Son precios de demostración para este proyecto académico.

¿Puedo pagar o solicitar un envío?

No. Esta versión es una demostración y no procesa compras, pagos ni despachos.

¿Se conserva mi carrito al cambiar de página?

Sí, cuando el almacenamiento del navegador está disponible. Para conservarlo entre páginas de forma consistente, abre el sitio con Go Live o un servidor local. Si borras los datos del navegador, el carrito se reinicia.
