Una tienda creada para aprender

Somos estudiantes de informática y creamos Inacap Shop como un proyecto académico de tienda tecnológica.

Reunimos componentes, equipos de audio y accesorios en un catálogo sencillo de recorrer. Buscamos que cada producto tenga una imagen, una descripción clara y un precio visible.

Este sitio es un prototipo desarrollado con Django y Bootstrap para demostrar el funcionamiento de un catálogo interactivo con carrito de compras en el navegador.
